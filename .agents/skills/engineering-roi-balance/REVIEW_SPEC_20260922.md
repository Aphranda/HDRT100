## 1. 对话规则（R1–R13，已收敛）

| 规则 | 内容 |
|---|---|
| **R1 只追加** | 新回合追加到**文件末尾的对应回合块内**。不得改写、删除、重排他人回合（更正只能新开回合并引用被更正项）。 |
| **R2 无共享写点（方案 E，2026-09-22 采纳）** | 不设共享 index/ledger：状态由回合头派生。**每方只写自己的流**（DSH → `REVIEW_DSH_20260922.md`，Codex → `REVIEW_CODEX_20260922.md`）。静态区（本文件）只在双方明确同意后更新，且写前按 R11 复核。历史线程 `REVIEW_THREAD_20260922.md` 为 **FROZEN**，其旧索引/台账不再权威。 |
| **R3 回合格式** | 标题必须是 `## <节号>. T<n> · <作者> · <时间> · <指纹前 8 位>[ · <可选标签>]`（例：`## 3. T1 · DSH · 2026-09-22 · 83BF9450 · v3 评审`）。回合体由两行**行首锚定**的注释界定：B = `<!\-\- TURN:BEGIN id=T<n> … -->`，E = `<!\-\- TURN:END id=T<n> -->`；B 与 E 相邻且其间为空 = 该回合**尚未应答**。正文与示例中如需提到它们，一律写作 `TURN:BEGIN/END 注释`，**不得以 `<!--` 开头复现**（否则会污染解析）。 |
| **R4 解析配方** | **前置硬要求：必须以 UTF-8 读取**。用 PowerShell 必须显式 `-Encoding utf8`／`[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8)`；按系统 ANSI（GBK）读取会把 `·` 与中文变成乱码，锚定正则**全部假阴性**（r4 实测：含 `·` 的配方 0 命中，纯 ASCII 宽松式 4 命中）。<br>回合体（行首锚定）：`(?m)^<!\-\-\s*TURN:BEGIN id=(?<id>T\d+)[^>]*-->\r?\n(?<body>.*?)^<!\-\-\s*TURN:END id=\k<id>\s*-->`<br>回合标题（**分隔符无关**，只用 ASCII 类 + 显式可选分隔符）：`(?m)^##\s+\S+\s+T(\d+)\s+(?:\u00B7\s+)?(\S+)\s+(?:\u00B7\s+)?(.*)$` → 编号 / 作者 / 余下字段；余下字段再用 `\u00B7` 拆分（时间、指纹、可选标签）。<br>实测反例：若不加 `(?:\u00B7\s+)?`，作者位会被分隔符 `·` 吃掉（r4 实测输出 `T2 | · | Codex · …`），使自写/他写判定失效。<br>非锚定匹配会命中 §0/§7 的说明文字，一律禁止。 |
