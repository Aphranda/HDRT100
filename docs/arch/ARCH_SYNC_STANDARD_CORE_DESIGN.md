## 1. 适用范围（甜区定义）

**纳入**：在通用 MCU 加标准物理层（同轴、标准以太网）上，实现 **10 至 100 ns 级**相位与触发
同步，且不依赖专用同步硬件、专用 ASIC 或专用时钟分发板。

**不纳入**：

- ms 与 µs 档——NTP、软 PTP、EtherCAT DC、CANopen 已经解决且成本更低。
- sub-ns 计量档——White Rabbit、计量级设备的地盘。

**"低成本"是本范围的结果，不是定义。** 规范的准入条件只写技术条件（通用 MCU、标准物理层、
精度 class），不写价格；价格会漂移，技术条件不会。

## 2. 术语与量定义

指标只有在**测试条件同时声明**时才可比。本规范要求下列每个量都必须带条件使用。

| 术语 | 定义 | 必须同时声明 |
|---|---|---|
| 相对相位误差 | 两节点同一标称事件时刻之差，以时间表示 | 观测面（哪两点）、触发条件、仪器等级 |
| 相位包络 | 观测序列中相对相位的极差（峰峰） | 窗口长度、窗口数、观测占空比 |
| 频率偏差 | 相对频偏 Δf / f | 拟合跨度、斜率分辨率（1σ） |
| 相位噪声 | 去线性趋势后残差的 rms | 采样间隔、样本数、测量噪声底 |
| 未观测区间 | 相邻观测窗口之间未被采样的时间 | 最大连续空档、总空档占比 |
| **连续锁相** | 全时段内相对相位始终在界内 | 需要连续观测能力或有界化论证 |
| **采样窗口锁相** | 仅观测窗口内相对相位在界内 | 必须附未观测区间的定量界 |

**SC-T0（强制）**：任何精度声明必须显式标注使用的是"连续锁相"还是"采样窗口锁相"。
**禁止**用后者冒充前者。

## 3. 时间与触发契约

| 条款 | 内容 | 可测判据 | 测试方法 |
|---|---|---|---|
| SC-T1 | 系统必须定义唯一共同时间基，且其 owner 唯一 | 存在唯一 owner 符号；任意时刻仅一个节点可发起时间修正 | 静态审查加双 owner 负测 |
| SC-T2 | 触发同时性：同一次触发在各节点输出边沿相对共同参考的偏差 | 依 §7 class | 外部仪器同时对多节点边沿打时间戳，取相对相位包络 |
| SC-T3 | 时间戳语义必须显式声明：分辨率、epoch、单调性、回绕处理 | 分辨率可测（等价 tick）；跨回绕无非单调跳变 | 边界注入跨回绕点，检查单调性 |
| SC-T4 | 相位保持（holdover）：参考失效后允许保持的时长与保持期内相位漂移界 | 保持期漂移不超声明界 | 断开参考，记录相位随时间，用频偏乘时间给上界 |
| SC-T5 | 未观测区间必须**有界化**：给出 `gap_drift_bound = 频率偏差 × 最大连续空档` 并声明依据 | 有界值加频偏实测加最大空档实测 | 相位序列线性拟合得频偏及其 1σ；统计最大连续空档 |

## 4. 校准契约

| 条款 | 内容 | 可测判据 | 测试方法 |
|---|---|---|---|
| SC-C1 | 每条 link 必须定义 base delay，每个节点必须定义 offset，两者语义分离 | 校准矩阵 N×N 全覆盖，无隐式默认值 | 矩阵完整性检查加缺项负测 |
| SC-C2 | 校准路径必须显式建模：物理链路、参考分配路径、连接器与电缆 | 每段延迟可标定且可追溯；电缆不等长带来的偏差能被吸收 | 环回法或交换法标定，重复性检查 |
| SC-C3 | 禁止运行态路径推断：运行期不得用观测反推路径参数 | 静态检查无运行期 path inference | 代码审查加反测 |
| SC-C4 | 校准数据必须绑定代际与 CRC，旧数据必须可拒绝 | 代际与 CRC 校验；旧数据被拒且不覆盖有效值 | 注入旧 CRC 数据的负测 |
| SC-C5 | 必须声明校准不确定度并计入精度预算 | 不确定度有来源分解（链路、分配、仪器） | 预算表审查并与实测包络比对 |

## 5. fail-closed 与降级语义

| 条款 | 内容 | 可测判据 | 测试方法 |
|---|---|---|---|
| SC-F1 | 参考丢失必须在声明时限内检出并进入声明状态 | 检出时限可测；行为与声明一致 | 拔除参考，测检出时间与状态迁移 |
| SC-F2 | 参考滑周必须检出，且不得静默退化 | 滑周计数单调；滑周后不得继续声称锁相 | 注入滑周（错相或瞬断） |
| SC-F3 | 链路或 ring 失联必须拒绝进入依赖共同时间的路径 | 失联时输出 fail-closed（拒发或停发），不是尽力而为 | 断链负测，观测输出与状态 |
| SC-F4 | 降级必须对外可观测：外部接口必须暴露降级原因 | 外部可读到降级码；码表版本化 | 接口一致性测试 |
| SC-F5 | 禁止静默降级：任何降级必须留痕且可复查 | 事件与证据中可查到降级记录 | 证据检查 |

注：参考滑周在 10 MHz 参考上单次即 100 ns，超过本规范全部相位预算，因此 SC-F2 是
**硬性**条款而非建议。

## 6. 一致性测试接口

| 条款 | 内容 | 可测判据 | 测试方法 |
|---|---|---|---|
| SC-X1 | **黑盒**：一致性测试只能通过外部接口，不得依赖被测实现的源码或私有符号 | 测试套件不引用被测实现源码 | 对测试工具做静态审查 |
| SC-X2 | 必须暴露最小观测面：状态、降级码、精度相关计数、校准代际 | 观测面清单固定且版本化 | 接口一致性测试 |
| SC-X3 | 测试必须**自证测量能力**：声明测量噪声底并证明其远低于被测指标 | 有噪声底标定报告；噪声底显著小于指标 | 同源分路或对同一边沿重复判定 |
| SC-X4 | 结果必须**可复核**：绑定固件指纹、配置与测试向量，并保留原始证据 | 收据含指纹与 digest，第三方可复现 | 独立复现试验证 |
| SC-X5 | 分级：厂商自测（强制）与第三方测试中心测试（认证）必须分离 | 两级流程及各自输出格式 | 流程审查 |

## 7. 精度 class 与合格判据（草案值，待冻结）

| class | 相对相位包络 | 频率偏差 | 最低测试条件 |
|---|---|---|---|
| A | 不大于 100 ns | 不大于 10 ppb | 观测不少于 60 s，窗口不少于 10 |
| B | 不大于 25 ns | 不大于 2 ppb | 观测不少于 600 s，窗口不少于 100 |
| C | 不大于 10 ns | 不大于 0.5 ppb | 观测不少于 600 s，且噪声底已标定 |

每档声明必须同时给出：连续锁相或采样窗口锁相、最大连续空档、测量噪声底。
**本节数值为草案，冻结前需以第二实现与独立测试验证。**

## 8. 当前实现对标（快照，非事实源）

依据 `out/HardwareAcceptance/20260919/dpll-delay-center-r2/` 的四板证据：

| 判据 | 现状 | 是否达标 |
|---|---|---|
| 相对相位包络 | 三通道约 24 ns 峰峰 | 达 B 档包络要求 |
| 频率偏差 | 不高于 0.004 ppb（2σ） | 优于 C 档频率要求 |
| 连续锁相 | `physical_continuous_lock_qualified` 为 false | **只能按采样窗口锁相声明** |
| 未观测区间 | `unobserved_intervals_qualified` 为 false；最大空档约 1.8 s | 需按 SC-T5 有界化 |
| 测量噪声底（SC-X3） | 约 3.8 ns rms 白噪声，来源未定位 | **未满足** |
| 黑盒测试（SC-X1） | 现有一致性测试为白盒（编译生产代码函数体） | **未满足** |
| 校准不确定度（SC-C5） | 未做来源分解 | **未满足** |

**结论**：技术指标已进入甜区（B 档），但**规范符合性还差计量与黑盒化两件**。

## 9. 条款冻结前置条件

1. 测量噪声底标定，并证明其显著低于目标 class 指标（SC-X3）。
2. 一致性测试黑盒化，与当前实现解耦（SC-X1、SC-X2）。
3. 第二个独立实现，用于证明规范充分性与无歧义（SC-X1 的前提）。
4. 未观测区间有界化方法落地为可复核证据（SC-T5）。
5. fail-closed 全项负测（SC-F1 至 SC-F5）。
6. 校准不确定度预算与实测包络比对（SC-C5）。
