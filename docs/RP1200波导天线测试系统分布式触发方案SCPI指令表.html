状态展开规则
项目说明
序列含义序列由多个确定状态组成；每个状态同时确定通道、极化、频点和波位，pol=2 时展开为 H/V 两态
状态数量chan_cnt × freq_cnt × wave_cnt × pol_expand；其中 pol_expand=1（pol=0/1）或 2（pol=2），例如 8×5×1×2=80
扫描位置角度范围由 CONFigure:ANGLe:SWEEp 给出，转台按相同 start/stop/step 输出目标角度脉冲；业务模型为角度脉冲外层、点内测试序列内层
角度命中A0 每收到一个有效角度脉冲，推进一个 angle_index，并完整执行一次 active sequence；执行完成后等待下一角度脉冲
推荐状态字段
字段范围说明
state_id0..N-1状态编号，由 CONFigure:TRIGger 自动展开生成，固定对应 switch1_ch -> pol -> freq_idx -> wave_idx 顺序，供 CONFigure:SEQuence 引用
switch1_ch1..8SWITCH1 目标通道（原 SP8T）
pol0 / 1 / 2极化展开后的确定值；0=H，1=V，2=BOTH，2 由内部展开成 H/V
freq_idx0..freq_cnt-1频点索引
wave_idx0..wave_cnt-1波位索引
switch2_sel0 / 1SWITCH2 目标选择（原 SP2T），可由极化或馈源策略生成
运行门禁
场景门禁拒绝处理
TRIGger:STARt配置 CRC、active 校准表、active 同步配置、active 序列 CRC、序列校验和运行态策略必须通过。读取 READ:SEQuence:ACTive?、SYSTem:CONFigure:STAT? 和 SYSTem:CONFigure:NACK?。
同步要求required_lock=1 时 SYNC 必须为 LOCKED，且 e_vdc、age、CRC 低于门限。读取 READ:SYNC:STATe?、READ:SYNC:HEALth?。

活动序列只允许在 IDLE/CONFIG/调试安全边界切换 active sequence；RUN 中不能替换本轮冻结序列。读取 READ:SEQuence:ACTive? 和 SYSTem:CONFigure:ACK?。
TRIG RUN只允许状态、日志、T2、fault 和 STOP 查询/控制；禁止配置、校准、同步和 DPLL 调试写入。返回运行态拒绝或 resource busy。
