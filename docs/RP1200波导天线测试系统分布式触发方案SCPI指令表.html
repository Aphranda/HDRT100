参数说明

参数取值说明

pol0 / 1 / 2极化；0=H，1=V，2=BOTH，其中 2 展开为 H/V 两态

序列配置指令
指令参数响应说明
CONFigure:SEQuence<plan_id>,<state_id_1>,<state_id_2>,...1一次性写入完整状态序列；state_id 必须引用当前 CONFigure:TRIGger 自动展开生成的状态表

序列状态定义

SP8T、SP2T、频点、波位与极化组合
2026-08-11 SCPI Reference
DTC100 Distributed Trigger
状态展开规则
项目说明
序列含义序列由多个确定状态组成；每个状态同时确定通道、极化、频点和波位，pol=2 时展开为 H/V 两态
状态数量chan_cnt × freq_cnt × wave_cnt × pol_expand；其中 pol_expand=1（pol=0/1）或 2（pol=2），例如 8×5×1×2=80
扫描位置角度范围由 CONFigure:ANGLe:SWEEp 给出，包含扫描起点、终点和步长；业务运行模型为扫描角度外层循环、角度点内测试序列内层循环，系统据此将输出脉冲映射到扫描位置，序列展开仍按通道 -> 极化 -> 频点 -> 波位排序
推荐状态字段
字段范围说明
state_id0..N-1状态编号，由 CONFigure:TRIGger 自动展开生成，固定对应 switch1_ch -> pol -> freq_idx -> wave_idx 顺序，供 CONFigure:SEQuence 引用
switch1_ch1..8SWITCH1 目标通道（原 SP8T）
pol0 / 1 / 2极化展开后的确定值；0=H，1=V，2=BOTH，2 由内部展开成 H/V
freq_idx0..freq_cnt-1频点索引
wave_idx0..wave_cnt-1波位索引
switch2_sel0 / 1SWITCH2 目标选择（原 SP2T），可由极化或馈源策略生成
断点与分段运行
指令参数响应说明
CONFigure:ANGLe:BPOint[angle_deg]1设置角度断点；给出参数时绑定指定扫描角度，运行中或暂停中省略参数时使用当前待输出的角度游标
READ:ANGLe:BPOint?breakpoint block查询当前角度断点配置、命中状态和断点游标
CONFigure:ANGLe:BPOint:CLEAr1清除断点配置；若当前已因断点暂停，仅清除断点标志，不自动继续运行
READ:TRIGger:STATe?state block读取触发运行状态，含模式、运行态、当前角度、角度索引、序列索引、late、错误和断点
断点逻辑说明
命中时机每个角度点开始前比较当前扫描角度；命中后进入暂停，该角度点对应的测试序列尚未输出
继续运行TRIGger:CONTinue 从命中的角度继续执行，并完整跑完该角度点内的测试序列；断点不进入点内序列
清除/停止CONFigure:ANGLe:BPOint:CLEAr 只清断点；TRIGger:STOP 停止运行但不改变断点配置；*RST 清除临时断点和运行游标
前期软件可以先按角度点和角度点内的完整测试序列开发界面和文件格式；断点只保存角度，不保存点内序列位置，命中后继续时该角度点内部序列全部测一遍。下位机后续可把角度映射到完整状态表，避免上位机逐脚控制开关。

校准指令

CALibration 动作指令与链路维护入口
2026-08-11 SCPI Reference
DTC100 Distributed Trigger
校准边界
校准是快速短事务，只计算线缆或触发链路固定 delay。CALibration:STARt 必须明确输入端和输出端，响应前完成测量；失败不覆盖旧 staging 数据。
链路表维护
指令参数响应说明
CONFigure:CALibration:LINK:ADD<type>,<src_node>,<src_port>,<dst_node>,<dst_port>,<direction>,<enable>,<required>1新增可校准链路；链路 key 已存在时返回 duplicate。
CONFigure:CALibration:LINK:SET同 ADD1修改链路属性；不修改已经保存的 delay 数据。
CONFigure:CALibration:LINK:DELete<type>,<src_node>,<src_port>,<dst_node>,<dst_port>[,DEL]1删除链路；带 DEL 时同时删除该链路校准数据。
READ:CALibration:LINK?[type,src_node,src_port,dst_node,dst_port]link table读取链路清单、方向、使能、必需标志和当前 delay 是否有效。
校准动作
指令参数响应说明
CALibration:STARt<type>,<src_node>,<src_port>,<dst_node>,<dst_port>result block快速测量指定输入/输出段，例如 CALibration:STARt SMA,A0,OUT1,A1,IN1。
READ:CALibration:STATe?[type,src_node,src_port,dst_node,dst_port]state block读取最近一次或指定链路校准状态；快速事务通常返回 DONE/FAIL。
READ:CALibration:RESult?[type,src_node,src_port,dst_node,dst_port]result block读取最近一次校准结果、delay、jitter、样本数和失败原因。
执行约束
约束规则上位机处理
运行状态只允许在 IDLE、STOPPED 或 CAL 模式执行。运行中拒绝时先 TRIGger:STOP，再重新校准。
链路存在CALibration:STARt 的端口对必须已在 LINK 表中登记。缺失时先执行 CONFigure:CALibration:LINK:ADD。
失败保护失败不覆盖旧 staging delay，只记录失败原因和原始计数。读取 READ:CALibration:RESult? 后决定是否重测。
同步影响校准写入 staging；只有 CALibration:ACTivate 后才影响 SYNC。激活后重新执行 SYNC:CHECk。
拒绝原因
reject_reason含义处理
RUNNING系统处于 TRIG RUN。停止触发后重试。
LINK_NOT_FOUND端口对未登记。先新增或修正 LINK。
PORT_INVALID节点、端口或对象类型非法。检查端口枚举。
CAL_BUSY已有校准短事务。稍后重试。
SIGNAL_TIMEOUT未捕获回传边沿。检查线缆、方向和映射。
QUALITY_FAIL质量超限。读取结果后重测或手动写入。

SYNC 动作指令与运行读取入口
2026-08-11 SCPI Reference
DTC100 Distributed Trigger
同步边界
同步基于 active 校准表，不重新测 delay。SYNC:STARt 只使用 active 同步配置，并要求最近一次 SYNC:CHECk 通过。
动作指令
指令参数响应说明
SYNC:CHECk[ACTive|STAGing]check block校验校准表、NODE 链路、CRC、时效、方向和拓扑；省略为 ACTive。
SYNC:STARt1启动同步环、虚拟 DC 维护和运行门禁服务。
SYNC:STOP1停止同步服务，退出锁定态。
SYNC:RELock1清除当前 offset/rate 估计并重新锁定；不清除校准表和同步配置。
SYNC:HOLDover0|11进入或退出保持态；保持态只允许已装载队列完成。
读取指令
指令参数响应说明
READ:SYNC:STATe?state block读取同步状态、锁定态、origin、seq、holdover 和 fault。
READ:SYNC:PARameter?param block读取绑定校准表、环路、DPLL 和门禁参数。
READ:SYNC:HEALth?health block读取 CRC、seq、drop、relock、e_vdc、late 和链路时效统计。
READ:SYNC:NODE?[node]node block读取单节点 offset、rate、last_seq、age 和链路健康度。
READ:SYNC:LINK?[src_node,dst_node]link table读取 NODE delay、hop 方向、required/enabled 状态和校验结果。
READ:SYNC:CHECk?check block读取最近一次同步检查结果和拒绝原因。
同步状态机
状态含义允许动作
IDLE未启动同步或已停止。允许配置、加载、检查和启动。
CHECKEDactive 配置和拓扑检查通过。允许 SYNC:STARt。
LOCKING正在估计 offset/rate。允许读取状态、健康度和维护 DPLL 调试。
LOCKED虚拟 DC 已锁定，满足运行门禁。允许 TRIG RUN。
HOLDOVER短时失去同步帧，按保持策略运行。不允许新增预约，只允许已装载队列完成。
FAULTCRC、seq、拓扑或门禁故障锁存。读取证据后停止并清故障。
故障与恢复
场景状态变化恢复动作
链路缺失/方向错误CHECk 失败。读取 READ:SYNC:LINK?。
CRC/seq 超限LOCKED->FAULT停止触发，读取 health 和故障证据。
短时丢帧LOCKED->HOLDOVER等待重锁或执行 SYNC:RELock。
e_vdc 超门限LOCKED->LOCKING/FAULT读取质量数据，排查链路或 profile。
故障锁存FAULT读日志后 SYSTem:FAULT:CLEAr。
