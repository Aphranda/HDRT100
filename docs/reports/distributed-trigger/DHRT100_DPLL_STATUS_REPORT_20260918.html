现有板卡：从百纳秒窗口向 ±50 ns 优化
优先压缩参考误差：继续缩短 NO1 事件时间戳采样区间，减少跨启动中心变化，校验本地 delay 与输出补偿，保持 PIO/DMA 连续执行。
以实测判定目标：±50 ns 指各从实际边沿相对 NO1 的误差目标，不是当前结论；固定补偿无法消除随机抖动，须覆盖全部节点、多次启动和长稳窗口。
更高性能平台：FPGA 支撑 ps 量级的演进路线
纯硬件实现现有算法：时间戳锁存 / 身份匹配 → delay 加法 → 残差计算 → 固定点 PI / DPLL 运算、限幅与状态更新 → NCO / 相位调节 → 定时输出 FPGA 流水线与状态机承担实时闭环；处理器仅负责配置、监控与维护 细分时间：TDC / 多相采样 + PLL / MMCM / 延迟器件；低抖动时钟与链路校准
FPGA 是可行方向：按器件与实现选择，可提供数十至数百 ps 量级的时间细分，并探索相应量级的板间锁相；具体精度由完整误差预算与实测决定。
分辨率与锁相精度分开：ps 级步进不自动等于 ps 级多板误差，更不表示达到 1 ps。当前 MCU 的 4 ns 基本节拍不能仅靠软件替换获得 ps 级单边沿控制。
演进路径：当前有限窗口 ±100 ns → 现有平台争取 ±50 ns → FPGA 探索 ps 量级。

内部研发阶段报告
当前百纳秒效果由多层共同形成：参考端提供共同事件时间，通信与匹配保证“比较的是同一件事”，本地 DCO 分别消除频率斜率和相位偏移，统一时基与硬件输出把修正兑现到引脚，独立 output delay 再居中固定输出差。示波器用于校验实际效果，不在实时控制环内。
组合关系：从参考事件到实际边沿
共同参考：NO1 自主 PI → 编码事件时间戳 确定性承载：TDMA 固定槽位 / PIO-DMA → 逐从接收与 ACK 本地判定：Core1 事件序号 + 代际匹配 → 加本地 path delay 本地控制：频率跟踪压低漂移斜率 + 中点相位校正消除偏移 共同坐标：TIMER1 → 本地 DCO 模型 → 未来 VDC 边沿反解 物理执行：独立 output delay → 固定前缀 / 后缀补给 → SYNC_IO PIO-DMA 外部证据：NO1 触发，四路实际输出同步记录 → 与 native DCO 对账
各部分解决的误差与必要边界
组成部分对当前锁相效果的贡献边界 / 缺失时的影响
① NO1 自主 PI 与参考编码本地主板持续调节，发布同一事件的闭环时间。收窄 DMA 对 PIO enable 的采样包围区间，减少参考区间不确定性。本轮 NO1 编码区间中位约 120 ns；NO1 自身抖动会进入各从参考，不能用编码分辨率替代精度。
② TDMA 特等席与身份匹配固定编码/槽位运输，Core1 直接按事件序号、会话与代际匹配；ACK 证明到达，拒绝旧代或错误记录。防止错配产生伪相位差；已到达不等于单圈期限已证明，ACK 不等于 DCO 已采用。
③ 本地有向 path delay把 NO1 事件时间换算到本节点预期到达时刻，为本地 residual 建立正确比较基准。方向、累计、资格需独立确认；不能用示波器输出偏差倒推出路径，也不能重复叠加。
④ 频率跟踪 + 中点相位控制频率跟踪抑制相位随时间漂移；中点估计把完整残差区间居中，避免停在最近零端点。经回执确认后纳入累计平移。频率优先，身份/模型/STOP 检查保留。区间中点是控制估计，不是更精确的测量值；±50 ppb 非本轮前置门槛。
⑤ TIMER1 与本地 DCO 模型参考观察、VDC 映射及 RUN 边沿计划使用一致时间坐标，减少 TIMER0/TIMER1 桥接的不确定性。当前 4 ns 一拍；四板 TIMER1 仍各自运行，必须通过 DPLL 模型跟踪才能成为共同时间。
⑥ PIO/DMA 连续执行Core1 只准备未来边沿并提交；硬件执行低/高电平计数。已提交前缀不改写，提前准备后缀、维护 FIFO 库存。把软件算出的修正兑现成 GPIO。FIFO 断流、迟补给或错误退休会破坏连续性，不能由模型计数推定实际脉冲。
⑦ 独立 output delay在输出侧加入每板可配置补偿，将剩余固定边沿差居中；当前候选 0/−28/−88/−160 ns。仅本轮 RAM 参数，不压低随机抖动、不消除频率斜率，不能替代路径校准或长期锁定。
⑧ 原生记录 + 外部示波器内部检查真实 DCO 采用与代际；外部检查四路输出差、周期连续性和修正方向。两类证据互相对照。属于验证层，不参与 Core1 闭环。并发 START 只改善首沿采集覆盖，不产生硬件同步或锁相能力。
为什么这组组合已经有效
误差被逐层处理：共同事件避免错配；本地 delay 建参考；频率环抑制斜率；相位中点消除偏移；输出补偿居中剩余差；PIO/DMA 保证动作按时间执行。
实测支撑：三从原生 −16～−18 µs 首次相位修正，对应输出约 +16～+18 µs 周期延长；两轮固定稳定窗口进入 ±100 ns。仍需长期与测量资格闭合。
达到当前效果的核心是 共同参考 + 同事件匹配 + 本地双层修正 + 硬件兑现，任何单独一项都不等于物理锁定。
