项目定位：DHRT100 是基于 RP2350 的分布式硬实时触发平台，目标是在多板节点之间形成共同事实、共同时间、确定性传输、预约分发和实际 T2（第二触发时刻）回读闭环。当前架构主线已从单板功能堆叠收敛到 HAOFV（融合型主动对象功能块向量架构）：AO（主动对象）管运行，FB（功能块）管状态机，Vector/RefMem（向量表/反射内存）管事实，TDMA（时分多址确定性通信）管传输，Calibration（校准域）管链路测量，VDC/DPLL（虚拟分布式时钟/数字锁相环）管共同时间。
当前结论：RefMem（反射内存）、TDMA（时分通信）、VDC（虚拟分布式时钟）和 Calibration（校准）均已建立独立主域和关键代码基础件；TRN-03A/B 已完成四板 raw-flight 与 process-image/FIFO 诊断闭环，TRN-03C/D 正在推进 active candidate、误帧压降、RX gate 和长稳门禁；文档自回归体系已成为跨主域防漂移机制。

四、架构核心规则
规则工程含义当前落点
唯一 owner每个事实、状态机和硬件资源只有一个 writer；外部入口只提交 intent 或读取 snapshot。AO（主动对象）/FB（功能块）/Vector（向量事实表）。

十一、VDC/DPLL（虚拟分布式时钟/数字锁相环）技术路线
对象技术路线状态
本地原始时钟local_tick_raw 是每块板自由运行、单调递增的原始硬件 tick；硬件 latch 锁存原始 tick，DPLL 不修改原始计数器。基础成立
时钟映射快照VdcMapSnapshot 维护 local_tick_raw 到 vdc_time（共同时间）的仿射映射：anchor、offset、rate、phase slew、epoch、quality 和 generation。首版完成
同步锁相功能块SyncDpllFB 借鉴 LinuxPTP/Chrony servo：相位误差、频率误差、Kp/Ki、outlier、jitter、RMS、holdover 和 reset 策略；P4-DBG 可用诊断样本调参。待长稳
EtherCAT DC 思想借鉴 EtherCAT Distributed Clocks（分布式时钟）的 reference clock、propagation delay、initial sync、drift compensation 和同步 timestamp；不采用 EtherCAT 协议。已纳入
DCO 快照DCO Snapshot 是数字控制振荡器只读快照，供 core1 的 FIRE_LOAD 和相位牵引消费；core1 不写 offset/rate。待接入
十二、硬件时间戳锁存与 VDC 的关系
关键结论：硬件 timestamp latch（时间戳锁存）不需要先有 VDC。它只锁存原始 local_tick_raw，因此系统启动时可以先用固定本地 tick 采集同步边沿；随后 DPLL 根据这些原始样本和校准 delay 形成 VDC 映射。VDC 锁定后，PIO 预约执行不直接读取软件 system_tick，而是由 core1 使用 VDC 的 local_from_vdc() 把未来共同时间反算为本地硬件 deadline；完成后再用 vdc_from_local() 回映射 T2_actual。
接口用途门禁
vdc_from_local()把 T2_actual_local、SYNC/READY latch 等原始硬件 tick 映射回共同时间。必须绑定 map_generation 和 mapping quality。
local_from_vdc()把未来 T_fire_target_vdc 反算为本地 PIO deadline。必须使用稳定 VdcMapSnapshot，guard 前 generation 变化需重算。
system_tick可以作为 VDC API 的只读封装，包含 offset/rate/slew。不能只是 local + fixed offset，也不能替代硬件 latch。
十三、T2（第二触发时刻）预约端到端流水线
raw local clock + hardware edge latch -> TDMA clock-training observation -> VDC DPLL offset/rate mapping -> Trigger future reservation in VDC time -> TDMA flight distribution + READY/fence -> VDC target-to-local inverse mapping -> sync_io / PIO executes local deadline -> hardware latches actual edge as raw local tick -> VDC maps completion back to common time -> RefMem/TDMA publishes completion evidence
十四、VDC 当前缺口
  • P4-DBG（调试路径）可先做 trace replay、sample admission、offset/rate/lock 曲线和参数扫描。
  • P4-LIVE（实时时钟路径）必须接真实 PIO 边沿 hardware latch、HARDWARE_TICK、分辨率和非 DIAGNOSTIC_ONLY flags。
  • active calibration CRC、link delay、bias generation 和 freshness 尚未完全接入正式 VDC lock gate。
  • 100 ns fine tier 需要稳定硬件 timestamp evidence、BAD_FRAME/WINDOW_BOUND 收敛和长时间验证。
  • core1 稳定读取 DCO snapshot 并驱动 FIRE_LOAD / sync output 的路径仍需验证。
十五、T2 当前缺口
  • TriggerReservationFB 的精确 wire layout 和 System Pack segment 仍未冻结。
  • READY/NACK、fence、completion 的丢帧策略、retry/fail-closed 和 watchdog/reset evidence 需要 HIL。
  • T2_actual_local 必须来自硬件 latch，不能由 CPU 查询或软件完成时刻填充。
  • 1/2/3/5/8 节点逐级验证尚未完成。
VDC/DPLL 的正确方向是“原始 tick 先可测、诊断算法先可跑、VDC live 只吃硬件 latch、预约用反向映射、完成用正向映射”。

十六、校准与训练流水线
阶段简述流程位置核心功能
拓扑线序先确认“谁连着谁”。建立板卡身份、邻接关系和环路顺序，避免后续测量套错节点。
时钟粗测先用 CLK 找大致时间窗。给编码循环和双向测距提供搜索范围，不直接当作精确链路延迟。
编码循环用 MARK 编码跑一圈。校准 MARK 环路基准和 marker 边界，确认编码能被稳定捕获和相关。
码元时隙SCK 独立校准，DATA 按 SCK 相位定窗。确定 SCK offset 矩阵、DATA 采样窗和码元中心，为短帧和测距提供相位预算。
双向测距在已校准时隙内锁存四个边沿。用 CLK 正向、DATA 反向的双程时间传递估算每条链路 delay candidate。
短帧闭环把训练结果接到 TDMA 短帧。验证 raw-flight、process-image、FIFO、bitmap 和动态 PIO persona 是否能同 generation 闭环。
active 候选把诊断证据升级为候选。只有 fresh P3、端点 bias、完整 link 集合和回滚路径满足后，才进入 active calibration。
可靠性/VDC最后接入产品门禁和共同时间。形成 RX gate、retry、health、soak、DPLL lock 和 T2 预约/完成回读证据。

十七、校准域时间参数
校准域输出的是可被 VDC/TDMA 消费的时间参数；双向同时对比法只是生成 path_delay/link_delay 证据的入口之一。 per directed link i: node_i -> node_(i+1) pio_instruction_period_ns = derived(clk_sys_hz, actual_pio_clkdiv, persona_id) node_tx_delay_i = pio_tx_launch + gpio_out + tx_chip_propagation node_rx_delay_j = rx_chip_propagation + gpio_in_sync + pio_latch + capture_quantization link_delay_i = node_tx_delay_i + path_delay_i + node_rx_delay_(i+1) loop_delay_origin_i = sum(link_delay_k + forward_residence_k + guard_k) bidirectional evidence for A -> B: t1_A=A.CLK_TX, t2_B=B.CLK_RX, t3_B=B.DATA_TX, t4_A=A.DATA_RX path_sum_AB = (t4_A - t1_A) - scale_B_to_A(t3_B - t2_B) link_delay_AB_observed ~= path_sum_AB / 2, then bias/freshness/asymmetry gates decide active.
校准参数定义/计算关系事实源和消费者
sample_period_nsraw_capture_clock periodPIO/DMA raw capture 和相关峰搜索的采样分辨率；决定 latch quantization、offset sample 和 residual 解释。
pio_instruction_period_nsderived(clk_sys_hz, clkdiv, persona)来自实际装载的 PIO persona 和系统时钟；TDMA 把 ns 预算换算成 cycles，不能用 RTOS tick 代替。
chip_propagation_delaytx_chip_pd / rx_chip_pd单端转差分/差分转单端芯片传播 delay，作为 endpoint bias 或 guard；不得在线缆 path_delay 上重复叠加。
node_delaynode_tx_delay + node_rx_delay板内 TX/RX、GPIO synchronizer、PIO latch、芯片传播和量化项；由同 persona reference loopback 建 bias generation。
forward_residencelocal_tx_latch - local_rx_latch节点切通/转发驻留时间，归入 loop/link budget；它不是线缆传播，也不由目标板 offset 代替。
path_delayphysical cable/connector propagation相邻板卡物理链路传播项；由编码循环、SCK/DATA 定窗和双向测距证据生成 candidate，active 后供 VDC `PATH_DELAY` 表消费。
sma_delaysma_tx/rx_endpoint + sma_cable_pathSMA 外触发/同步路径的独立校准项，来自 SMA sweep/loopback；可供触发预测和 VDC 事件对齐使用，不能与 RJ45/TDMA ring path_delay 混用。
link_delaynode_tx + path_delay + node_rx + capture_q一条 directed link 的端到端训练 delay；TDMA 用于 RX window、link budget 和 phase matrix，禁止由 loop aggregate 均分。
data_offsetrelative receive-window offsetMARK/SCK 锚定后的 DATA 采样窗相对修正；它是窗口参数，不等同于 path_delay 或 loop_delay。
guard_delayjitter + asymmetry + margin温漂、抖动、方向不对称和重复统计残差的保护项；参与 link/loop budget，不作为已测物理 delay。
loop_delaysum(link_delay + residence + guard)从某 origin 出发返回本节点的整圈预算；只用于 feedback window、timeout 和整圈残差，不替代 per-link delay。
生成阶段输入给下一层的输出
profile 固化clk_sys、PIO clkdiv、persona_id、码本、baud/profile CRC。`pio_instruction_period_ns`、bit period、half-chip 和 cycles/ns 换算事实。
endpoint bias同 persona 板内 reference loopback、芯片传播 guard、latch flags。`node_delay` / bias generation；缺失时 `path_delay` 只能保持 diagnostic。
编码循环MARK 编码、raw PIO/DMA capture、相关峰和粗窗口。marker origin、搜索窗、reject reason，不直接发布 active link delay。
SCK/DATA 定窗SCK 独立校准、DATA 码元窗口、repeat residual。receive-window offset、guard、phase matrix 和 short-frame ARM 相位预算。
双向测距证据同 epoch 四边沿硬件 latch、residence、bias generation。`path_delay` candidate、asymmetry bound、freshness 和 per-link 质量分数。
整圈预算全部 directed link、forward residence、guard、profile/schedule CRC。`loop_delay`、feedback timeout、residual gate 和 TDMA raw-flight/process-image 门禁。
