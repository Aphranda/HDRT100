F3 位置承载：广播语义与读数纪律

已成立 | 上一版的一处判断已作废
2026年10月16日星期四
内部评审阶段报告
实验快照，非冻结契约
本页定位：位置怎么送到各板、该用什么读数判断，以及上一版报告在这里的口径更正。
一、承载语义（本轮定案）
分发方式：车道对全部板广播同一批位置时间片（不是按板分发，也没有按板配额） 板上行为：一旦收到（冻结的）时间片，就按本板静态配置的「规划距离」推出动作 动作时刻 = 冻结时间片 + 本板静态延时（延时在部署期预先配好） 执行条件：收到即执行，不再等第二次下发 本轮更正：上一版报告的「按目标板分发 / 公平性 / 逐板到位率」作为目标不成立，该口径已作废
二、那「某块板读数偏低」说明什么
车道路径的接收量在三块板间出现离散时，说明的是接收侧（单深度邮箱 + 有界转交环）的争用与背压，不是分发不公平或缺位置。缺位置要在「广播 → 板内消费 → 冻结 → 执行」这条链路上查，不能在分发表上查。上一版据此提出的「改为每目标独立副本或单播」据此不再作为待办。
三、本轮实测：均衡性已大幅改善
读数修复前本轮
三从板车道路径接收134k / 66k / 134k（相差一倍）49.5k / 48.2k / 49.5k（几乎相同），更高速率下 111.6k / 108.6k / 111.5k
有界环丢弃176k–214k3.3k–9.6k（降约 20–60 倍）
被压垮的板每轮固定有一块完全不消费三轮均三块同时消费且执行 354–360
四、读数纪律（仍必须遵守）
• 判定分发只看一等席车道的接收计数（仅解码并提交成功才自增）。
• 经典的接收完成计数在一等席拥有运输时被设计性跳过，正常分发下恒为零；按它判读会得到相反结论。
• 位掩码类读数不是计数：例如「7」表示三个槽位，不能读成七次。
结论：F3 成立——广播承载、三块板均衡消费；分发「公平性」一说不成立并已撤回
