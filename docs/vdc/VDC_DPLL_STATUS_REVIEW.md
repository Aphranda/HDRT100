## 1. 当前结论

四板已经具备实际 DPLL 相位闭环：NO1 自主 PI 发布参考，NO2–NO4 接收后本地匹配、
调节 DCO，并在实际输出上消除微秒级偏差。最新两轮完整的一秒四路记录同时覆盖
启动首沿与随后收敛；在相对 NO1 首沿的 0.4～0.9 秒窗口内，三从各 500 组条件同序
边沿差均在 ±100 ns 内。内部首次相位修正与外部周期延长的方向及幅度吻合。

目前可以确认“实际闭环有效，有限窗口达到百纳秒量级”。仍不能授予正式长期完全锁定：
独立首脉冲身份、长期连续性、跨启动稳定性、测量不确定度和路径误差预算尚未全部闭合。
最终 VDC 时间、有效性、质量及代际一致发布仍待验收。

### 当前板卡基础与优化展望

以下为当前配置/实测快照，非新增硬件契约：

| 项目 | 参数与依据 |
|---|---|
| 处理平台 | RP2350B，Core0 控制管理、Core1 确定性处理；板级约束见 `docs/hardware/RP2350B_QFN80_IO_CONSTRAINTS.md`。 |
| 链路与介质 | 四板闭合环路、5 m 网线、10 Mbit/s 通信速率（本次用户确认的实验条件）。100 ns/bit 是传输位宽，不是同步精度下限。 |
| 系统时钟 | `boards/rp2350_trig/inc/board_config.h` 的 `BOARD_SYS_CLOCK_HZ` 当前为 250 MHz 超频配置，即基本节拍 4 ns。 |
| 时间坐标 | `components/vdc_domain/src/vdc_timestamp_clock.c` 将 TIMER1 接 clk_sys，提供 64 位计数；TIMER0 保留系统计时。 |
| 输出执行 | `BOARD_SYNC_PIO_FAST` 指向 PIO0，SYNC_IO 与 DMA 执行预提交边沿；分频为 1 时基本指令节拍 4 ns，边沿间隔还取决于程序。 |
| 实验输出 | 四板 OUT1 约 1 kHz、2 µs 高电平、5 V 标称，属于板级输出，不是 MCU GPIO 电压规格。 |
| 采样 | 本轮一秒记录为 20 ns 网格；另有 0.2 秒 / 4 ns 网格证据。样点间隔不等于校准后的测量精度。 |

已确认物理线序为 **NO1 → NO2 → NO3 → NO4 → NO1**，对应本次 P3 的
`out/HardwareAcceptance/20260918/p3-phase-center-r3/known-topology-source.json` 中 `ring_order`。
NO1 发布参考，三从沿途接收、加本地 delay 并闭环，ACK 沿环路返回。

现有板卡仍有提升空间：继续缩短参考时间戳采样区间，减少跨启动中心变化，
校验路径与输出补偿、硬件执行连续性及测量误差，下一阶段**争取 ±50 ns**。
该数值是各从实际输出相对 NO1 的待验证目标，不是已达到的指标；需覆盖全部节点、
多次启动和长稳窗口，不能仅将固定偏移居中就宣告完成。

更高性能平台可沿用共同参考、确定性传输、从板本地闭环与硬件定时输出的架构。
**FPGA 是向 ps 量级推进的可行路线**：采用 TDC/多相采样、PLL/MMCM 相位细分、
可编程延迟或外部精密延迟器件，并结合低抖动时钟、确定性收发、链路/通道校准和温漂补偿。
按器件与实现选择，可提供数十至数百 ps 量级的时间细分，探索相应量级的板间锁相；
最终精度依赖完整误差预算和实测。ps 级分辨率不自动等于 ps 级锁相精度，亦不表示达到 1 ps。
当前 MCU 的 4 ns 基本节拍不能仅靠更换软件获得 ps 级单边沿控制。

迁移方向是**以纯硬件实现现有算法**：时间戳锁存与身份匹配、delay 加法、残差计算、
固定点 PI/DPLL 运算、限幅和状态更新、NCO/相位调节与定时输出由 FPGA 流水线和状态机承担。
保留现有参考、事件身份、闭环及失效恢复语义，处理器仅负责配置、监控与维护；
固定点位宽、截断误差和流水线延迟须验证，硬件化本身不消除时钟及物理链路误差。

### 当前输出频差与内部 DCO 修正

对最近两轮 RAW 校验全部块哈希后，沿用 0.4～0.9 秒稳定窗口、每从 500 组条件同序边沿，
分别线性拟合 NO1 与从板的边沿时间相对于序号的斜率（周期）。相对频差计算为
`(NO1 拟合周期 / 从板拟合周期 - 1) × 1e9 ppb`，正号表示从板输出较 NO1 快。

| 节点 | 第一轮输出相对频差（ppb） | 第二轮输出相对频差（ppb） | 第一轮末态 DCO 修正（ppb） | 第二轮末态 DCO 修正（ppb） |
|---|---:|---:|---:|---:|
| NO1 | 参考 | 参考 | 不由相对输出推算 | 不由相对输出推算 |
| NO2 | −8.4 | +2.7 | +2295 | +2495 |
| NO3 | +2.2 | +6.1 | +2474 | +2669 |
| NO4 | +4.1 | +13.6 | +4834 | +5023 |

这些实测快照表明有限稳定窗口内相对输出漂移较小；拟合包含闭环相位校正的作用，
**不是瞬时频差、晶振自由运行误差或长期 ±50 ppb 认证**。内部 DCO 修正是相对于
各自本地时基的调节量，不能当作输出剩余误差；STOP 末态与波形窗口也不是同一时刻。
NO1 仅作为相对参考，其绝对频率精度没有外部标准溯源。
20 ns 采样网格、通道间测量不确定度、半秒窗口及条件序号配对的限制继续保留。

复算脚本与结果：`out/HardwareAcceptance/20260918/dpll-extended-window-r1/analyze_report_frequency.py`
及同目录 `report-frequency.json`；源数据为两轮 `capture/scope/`，内部值见各轮
`native-scope-review.json`。结果同时用相位漂移斜率反算核对，未进行逐通道时间平移。

## 2. 实现路线与 HAOFV 边界

| 环节 | 当前路线 | 证据边界 |
|---|---|---|
| NO1 | 本地自主 PI 调节并发布最小 typed 时间戳 | 不负责逐从计算校准命令。 |
| 运输 | 固定编码记录、固定邮箱、TDMA 飞行路径及 ACK | 已有到达与采用证据；完整单圈期限不能由“能收发”推定。 |
| NO2–NO4 | Core1 按事件序号/代际匹配，加入本地 path delay，独立修正 DCO | 三从均有真实频率及相位更新、原生记录与末态模型对账。 |
| 输出 | Core1 准备/提交，SYNC_IO PIO/DMA 执行实际边沿 | 输出 delay 独立应用，不能由示波器差值反推 path delay。 |
| 时间基准 | DPLL/VDC/SYNC 使用 TIMER1；TIMER0 保留系统计时 | 当前一拍 4 ns 是时基分辨率，不是锁相精度。 |
| 观测 | RUN 写有界原生记录；STOP 后导出，示波器硬件触发采样 | SCPI 只做 STOP 配置和触发，运行期间零查询。 |

实时路径继续保持 Core1 不等待 Core0、不经过普通解析/RefMem 分片/RTOS 或动态分配。
本轮实验只调整外部采集与 STOP RAM 参数，没有修改 OTA 或增加固件实时负担。

## 3. 最近解决了什么

1. **相位控制的居中估计。** 旧策略把残差推向最近的零端点，宽区间可能从两侧停在
   不同位置。`priority_phase_delta()` 改为完整区间的限幅中点估计；原始上下界保留，
   频率优先、发布回执、累计平移和 STOP/身份取消继续生效。新相位 schema 6 与历史
   schema 4 分开严格解码，避免旧解码器误判新策略。
2. **独立输出补偿。** 当前实验候选 NO1/NO2/NO3/NO4 为 `0/-28/-88/-160 ns`。
   仅在 STOP 写入 RAM，逐板核对请求、RUN 实际值和恢复值；结束后恢复原值，未 Flash
   固化。固定偏移可以居中，抖动和测量区间宽度不会因此自动缩小。
3. **四路首沿覆盖。** 原串行 START 跨度约 219 ms，超出 200 ms 记录，裁掉了
   NO3/NO4 首沿。受控并发 START 使用四个已核验的独立端口，全部事务结束并收到真实
   OK 后才继续 TRIAL；失败统一 STOP。主线程统一落日志，避免并发写文件。
4. **正确的示波器长窗口。** 保留旧 offset/时基读回错误及全低无效波形，未放宽判断。
   修正 RUN/MAIN/时基配置顺序并核验完成后，实际取得 50 M 点、一秒窗口、20 ns 网格。
   启动与稳定段来自同一份连续记录；较大的存储请求没有实际生效，不作为仪器能力。

## 4. 四板实测结果

设备为 NO1–NO4；示波器 `HDO4A244301137` 的 CH1–CH4 分别接各板 DPLL OUT1，
探头 1×，以 NO1/CH1 上升沿触发。NO1 OUT4 已接 EXT，但当前 RUN 只驱动 OUT1，
所以实验不把 OUT4 接线当成有效 RUN 外触发。

最新两轮使用相同源码和相同输出补偿，实际记录范围为相对 NO1 首沿 −0.1～+0.9 秒。
首沿之前均有低电平。分析按各板 `first_ordinal+j` 条件配对，不采用最近边沿或整周期
平移。下表取固定的 0.4～0.9 秒窗口，每轮每从 500 组，单位 ns：

| 节点相对 NO1 | 第一轮最小～最大 | 第二轮最小～最大 |
|---|---:|---:|
| NO2 | −60.17～−0.002 | −0.30～+39.89 |
| NO3 | −79.09～−2.14 | +0.11～+59.55 |
| NO4 | −79.89～−19.94 | −20.93～+20.22 |

两轮均完整通过原生记录、DCO 末态、STOP 和参数恢复核验，每轮完整流程约 131 秒。
第一轮三从围绕各自极值中点的半峰峰值分别约为 30.1/38.5/30.0 ns，说明有限窗口内
**波动幅度已进入 ±50 ns**。该中心为 `(min+max)/2`，不是 NO1 零点；相对 NO1 的
最大偏差仍约 −79.9 ns。图中没有逐通道居中处理，下一步重点消除中心偏移并验证跨启动重复性。
跨启动中心仍有变化，因此不把这组补偿视为永久校准值。第一轮窗口是在查看连续曲线后
选取，第二轮沿用相同窗口复测；两轮有限结果不代替预先定义的长期验收。

此前另一次 4 ns 采样网格、0.2 秒稳定期记录也通过，NO2/NO3/NO4 范围分别约为
−32～−13 / −35～−21 / −64～−48 ns；改变边沿检测阈值未明显改变结果。
它仍是另一轮近邻模周期证据，不用于补接最新记录的绝对序号。

![第一轮连续启动与收敛条件对账](../../out/HardwareAcceptance/20260918/dpll-extended-window-r1/startup-one-second-r1/startup-conditional-phase.svg)

第一轮内部与实际输出的修正量对比如下。负的本地相位平移对应后续实际边沿延后，
由一个较长周期完成；不能把这类约百分之一周期的伸长误当成缺少整个脉冲。

| 节点 | 原生首次 phase delta（ns） | 外部最大周期延长（ns） |
|---|---:|---:|
| NO2 | −16578 | +16580 |
| NO3 | −17451 | +17442 |
| NO4 | −17782 | +17780 |

这是方向/幅度一致的证据，尚不是带独立硬件标签的逐事件因果证明；几 ns 的差值也不
代表仪器已达到几 ns 的绝对测量精度。
