关键检查点

DIFF0、DIFF1、FWD_TRIG_DIFF 独立； 串联桥必须重驱 CLK/MA 与 DATA/SLO； BiSS-C 是协议 persona 的一个子集，同硬件可切换到 HSPI_LIKE_AUX； U2/U3 按 RJ45 端口侧放置，每颗 ISO1452 都是一收一发； RJ45/ISO1452 差分入口默认使用 ESDS302-Q1，A/B/Y/Z 每线 10R 串联阻尼靠近 ISO1452，隔离总线侧默认 5V 供电； U5/U6 使用两颗固定方向 ISO6440F/ISO7740F 承载 SMA 装配矩阵； SMA 输入 AFE 固定为 TPD1E05U06DPYR + SN74LVC2G17QDCKRQ1，输出驱动固定为 SN74LVC2G34 + TPD1E05U06DPYR； GPIO23 固定为 RJ45_FWD_TRIG_OUT； 保护、端接、隔离、收发器延迟和线缆延迟都进入 latency offset 标定。
