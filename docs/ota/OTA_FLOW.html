方式：--method ota（默认）走 USB CDC 流式 OTA，4096 B 块、A/B 槽提交，保留已存标定， 是验收凭证依赖的路径；--method picotool 经 BOOTSEL 加载 DHRT100_FACTORY.uf2 （bootloader + 槽 A + boot control），需 --allow-factory-image，本台架曾因此丢失标定； --method tdma 为 TDMA 环上流式 OTA 预留位，尚未实现，Step 3/4 会明确判为失败，绝不显示为刷写成功。
构建号：PROJECT_BUILD_ID 在 CMake configure 时缓存，增量构建不变， 所以刷写前后构建号相同不能证明新镜像已落盘（Step 2 会提示）；以包 SHA256 与修改时间辨识镜像。
标定保持：Step 6 比对 READ:CALibration:TRAINing:STAGe:PERSistence? 刷写前后的记录身份， 变化即失败，需重新标定后再跑 DPLL60 / T2。
凭证：本页只是工作流记录，不是验收凭证。
运行：python tools/ota/OTA_workflow.py --full， 或 --steps 2,5,6 只复验不刷写；--refresh-html 用最近一次数据重绘本页。
