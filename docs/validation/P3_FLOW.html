#步骤状态 调用耗时原因 / 备注
一条代码路径：p3_hardware_acceptance.py run 与本工作流 --profile full 执行同一组步骤函数（ACCEPTANCE_STEPS）。每步只读运行状态 （workflow-state.json）与运行目录里的证据，缺输入时按名失败并指出产出它的步骤。
凭证：只有当所需步骤在同一运行目录、同一源码指纹下按序全部运行时，步骤 35 才写提交凭证； 重跑上游步骤会使下游步骤过期，沿用（REUSED）的标定目前只出 workflow-record.json，配置中的凭证保持不变。
运行：python tools/hardware_acceptance/hardware_acceptance_workflow.py --list； --profile full；--profile retrain --run latest（重做 TRN-02 起直到收尾；DPLL 须紧跟 TDMA，故无单独的 DPLL profile）； --profile firmware --reuse-from latest；--profile offline --run latest（不碰台架重算门限）。
