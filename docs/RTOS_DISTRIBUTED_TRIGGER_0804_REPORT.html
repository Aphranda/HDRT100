四板业务拓扑
A0 只生成基准和调度；A1/A2/A3 在各自设备近端本地输出，不等待串行动作链
节点业务角色关键输入关键输出
A0扫描主控 / 转台 / DPLL / ring originSMA_IN1 接 Compare Out；A3 转入配置/控制RJ45 下发 SYNC/FIRE_LOAD；硬件内部自循环
A1DUT / 链路 / SP8TRJ45 同步预约；SMA_IN 捕获 DONESMA_OUT 切换 DUT/链路；RJ45 回传 A1_DONE
A2馈源 / 极化 / 开关RJ45 同步预约；SMA_IN 捕获 DONESMA_OUT 切换馈源/极化；RJ45 回传 A2_DONE
A3上位机网关 / VNA / 网分USB/USBTMC 配置；RJ45 预约；SMA_IN READY转发配置/START/STOP；触发 VNA；回传数据状态
业务时序原则
并行预约：A1/A2/A3 收到同一个 T_fire_base，根据本节点 Δt_i 到点动作。
DONE 不串行触发：A1_DONE/A2_DONE 用于闭环验收和决定 A3 是否采样，不用于实时触发下一块板。
短线近端：设备触发线只保留板到设备近端段，降低暗室/伺服环境长线耦合风险。
异常剔除：late、CRC、READY 超窗、乱序样本不进入 DPLL 和射频有效结果。
设备动作编排
每个角度点按同一个基准展开：DUT delay、FEED delay、VNA delay。单点节拍由最慢设备建立时间决定，不再是多个设备串行等待之和。
核心认知：环路传预约和状态，SMA 输出真实边沿；通信包到达时刻不直接变成业务触发时刻

RJ45_SYNC_RING 同步环：实现方法
GPIO26 输出、GPIO27 输入，四段点对点固定方向差分链路；帧首沿作为时间戳基准
帧类型发送方作用进入实时链路的内容
SYNCA0虚拟 DC offset/rate 更新首沿时间戳 + seq；payload 不决定边沿
FIRE_LOADA0未来预约触发装载seq、T_fire_base、mask、pulse_width、CRC
A1_DONE / A2_DONEA1/A2动作完成与状态确认seq、T2_i、status、error_code
MEAS_DONEA3VNA READY/REDY 已捕获seq、T2_vna、valid/timeout
FAULT任意板late、CRC、断线、超窗、互锁只进入状态机和日志，不补救已过期触发
推荐首版
12.5 Mbps，20 cycles/bit @250MHz，先做 1e6 帧 CRC=0 和边沿分布统计。
高速档
20.833 Mbps，12 cycles/bit，适合 PIO 整周期时序，但对收发器和走线更敏感。
禁止事项
不把多板挂成共享总线；不运行中切方向；不把 DONE 当作串行实时触发边沿。

虚拟 DC 时间模型
RP2350B 没有 EtherCAT DC 硬件计数器；用本地 tick + offset/rate 建立可校准时间轴
本地 tick
local_tick = clk_sys tick
1 tick = 4 ns @250 MHz

PIO 负责短窗口计数、边沿捕获和到点输出；CPU 扩展 64-bit 时间戳。
虚拟 DC 映射
dc_tick = local_tick * rate_q32 + offset_tick

offset_tick 修正相位；rate_q32 修正频率；A0 是 ring origin。
变量含义更新方式
offset_tick本板到 A0 虚拟 DC 的相位偏移SYNC 帧捕获边沿 + 多轮平均 / DPLL
rate_q32本板本地时钟相对 A0 的频率修正连续 SYNC 帧相位斜率估计，低带宽平滑
Δt_i节点/通道/设备补偿量出厂校准 + 现场交叉测试 + 慢速温漂修正
delta_ticksPIO 短窗口倒计时CPU 将未来 T_fire_i 换算为本地相对 tick
t_margin预约装载提前量必须大于队列、PIO 装载和通信抖动裕度
实现边界
PIO 不能直接读取系统 timer，也不维护完整 64-bit DC。所有绝对时间比较由 CPU 转换成短窗口倒计时；过晚预约直接 late，不补发。
时间轴不是芯片典型值，而是 同步帧边沿 + 回环标定 + 长时间分布统计 的工程结果

T2 回读与闭环校准
每个动作必须带序号回读，先验收“是否实际动作”，再让有效样本进入 DPLL 和补偿表
SMA 输入捕获
A1/A2/A3 使用 GPIO20..23 捕获设备 READY、完成脉冲或输出回环。PIO 运行 capture_window，CPU 按窗口计数、loop_cycles 和通道校准扩展为虚拟 DC 时间戳。
回读字段
seq、node_id、channel、T2_i、status、error_code、temperature、late_count。
样本状态是否进入环路处理方式
VALID是计算 e_i、e_act，可进入共模残差和慢速 Δt_i 更新。
LATE否本次预约过晚，禁止补救触发；记录队列和通信诊断。
TIMEOUT否READY/T2 超窗，动作有效性未知；本次射频样本无效。
REORDER否序号乱序或重复，不进入 DPLL，避免污染预测。
FAULT否互锁、CRC、断线或输出异常；锁存故障等待人工/上位机清除。

首版预算量级为百 ns；P99.9 必须由统一统计口径的四板实测分布闭合，不能用混合门限 RSS 替代。

同板输入到输出典型 50-300ns，按 ≤1µs 验收；该指标不代表跨板同步误差。
角度误差换算计算式说明
速度误差引起时间误差δt≈T_pred·δω/ω预测提前量越长、瞬时速度扰动越大，触发时间误差越大；需预跑 + DPLL 限制。
时间误差转角度误差Δθ=ω·Δt10°/s 下 50µs 对应 0.0005°，DPLL 不按纳秒级预测误差冻结。

RP2350 PIO 实时执行边界
三组 PIO 按实际 pin map 分域：PIO0 输入捕获，PIO1 输出触发，PIO2 保留 BiSS/协议
PIO 职责GPIO核心动作边界
capture_windowGPIO20..23 + GPIO27采样 SMA_IN 和 RJ45_IN，捕获边沿时 push 通道 bitmap 与窗口计数。分辨率按 loop_cycles 标定，不等同于 1 tick。
local_fireGPIO16..19pull delta_ticks/mask/pulse_width/polarity，到点输出 SMA 脉冲。CPU 必须提前装载；late 禁止补救。
ring_rx_txGPIO27 输入 / GPIO26 输出同步环帧首沿时间戳、payload 解码、固定延迟转发或状态回传。首版用 12.5Mbps；CRC 错误只进入诊断。
biss_reservedGPIO24/25/28/29BiSS/SSI/RS422 位置源或协议辅助。不作为四板同步主链路，避免协议与触发混用。
硬实时留给 PIO
边沿捕获、短窗口倒计时、脉宽保持、通道 mask 输出全部在 PIO 中完成。
数学留给 A0 CPU
64-bit 虚拟 DC、offset/rate、DPLL、异常剔除、补偿表、运行日志由 A0 下位机完成；上位机只配置和读取。
DMA 用于持续流
连续捕获、长序列输出和批量采样必须使用 DMA，避免 IRQ 把实时链路打爆。
实现红线：触发模式 armed 后不得切换已分配 PIO 输出 GPIO 的 owner 或 GPIO base

风险识别与应对措施
按 IO 口径、同步链路、实时执行、设备接口和工程交付五类风险归口
风险项概率影响应对措施
固件沿用旧 GPIO16..23 输入/输出表中高编译期 pin map 断言；启动自检逐通道闪测；测试文档以 2026-08-04 网表为准。
GPIO20..23 输入反序导致通道错配高高驱动层统一 bit reverse 或通道表解释；每个 SMA 端口独立回环验收。
RJ45 同步环延迟温漂或链路不稳定中高单段 hop 标定、端接检查、12.5Mbps 起步、长时间统计、断线注入。
RP2350 原型被误写成 FPGA/EtherCAT 指标中高报告明确 e_vdc/e_q/e_act/e_pll 边界；亚 ns 和 <10ns 跨板指标需升级硬件。
设备 READY/T2 不可用或抖动大中中ICD 前置定义 READY 极性、脉宽、超窗；无法回读则用示波器或设备日志替代闭合。
DPLL 追随噪声导致失锁中高正式采集降低带宽；异常样本剔除；连续超 50µs 降速、停采或重锁。
GND-FGND 多点跨接影响隔离中中单点 0R/DNP 策略；跨地电容默认装配状态写入 BOM；USB 调试供电标识旁路隔离。
BOARD_CUR2 浮空 ADC 被周期采样中低固件禁采未接前端 ADC；硬件版本由烧录配置/固件常量声明。
先冻结硬件口径指标只按实测承诺异常样本不入环路射频指标独立验收

总结结论与实施策略
RP2350B 四板方案可作为百纳秒级分布式触发原型进入工程验证，但必须按新版网表和分层指标执行
结论项RP2350B 方案口径前置动作
硬件 pin mapGPIO16..19 输出，GPIO20..23 输入反序，GPIO26/27 RJ45，同步主环不使用旧 AUX0..AUX3。固件、测试脚本、文档同步新版网表。
同步机制RJ45_SYNC_RING 建立虚拟 DC；同步帧首沿用于时间戳，payload 不直接产生业务边沿。四板 1e6 帧、1h 起步、断线恢复统计。
触发执行A1/A2/A3 提前装载 PIO local_fire；SMA_OUT 到点输出；late 预约拒绝执行。统一示波器回环，验证边沿残差和 late_count。
闭环验收用 T2_i 计算 e_act；DPLL 只评价 e_pll；射频结果独立验收。ICD 定义 READY、极性、脉宽、最小间隔、超窗行为。
指标承诺首版 e_vdc P99≤100ns、e_act P99.9≤300ns、e_pll P99.9≤50µs。所有指标以实测分布冻结，不用芯片典型值外推。
