# 标准：归档流程

Last updated: 2026-10-10

状态：**标准（normative）**。适用于 `out/**` 与 `tools/**` 的整理。

## 1. 三分类判定

| 类别 | 判据 | 处置 |
|---|---|---|
| **保留（evidence/keep）** | 验收证据、凭证引用、当前构建树、被文档/门禁引用的工具 | 原位不动（`out/` 证据允许冷热分层） |
| **冷数据（cold）** | 不再活跃但仍需追溯（历史实验、旧评审、旧日志、探测快照） | 移入 `archive/cold/<类别>/` |
| **可删除候选（deletable）** | 可由源码/工具**重建**，且**无任何引用**（编译缓存、测试缓存、worktree 副本、未引用一次性目录） | 移入 `archive/deletable-candidates/<子类>/` |

**判定必须留痕**：写入对应清单（`OUT_ARCHIVE_MANIFEST.md` / `REFERENCE_AUDIT.md`）。

## 2. 操作规则

1. **只移动、不删除**；删除由用户确认后执行。
2. 移动前**校验解析后的绝对路径**（防止误操作系统目录或跨卷复制）。
3. 同卷移动优先（元数据操作）；跨卷移动需评估耗时并在清单记录。
4. 移动前打印/记录**将被移动的对象清单**；失败项逐条记录（原因 + 保留原位）。
5. 不得移动证据与凭证引用产物；不得移动禁止移动集。

## 3. 冷热分层

- 默认阈值：`out/HardwareAcceptance/<日期>/` 中**超过 30 天**的运行移入
  `archive/cold/misc/acceptance-<年月>/`；**凭证相关目录与最近 30 天保持原位**。
- 阈值可由用户调整；调整须记入清单。

## 4. 清单维护（每次归档后必须更新）

字段：**动作**（移动了什么、源 → 目的地）、**规模**、**例外/失败**、**未决事项**、**日期**。
`out/` 更新 `OUT_ARCHIVE_MANIFEST.md`；`tools/` 更新 `REFERENCE_AUDIT.md`（含"旧 → 新"映射）。

## 5. 删除流程（用户执行）

1. Agent 只负责把候选**移动**到 `archive/deletable-candidates/` 并在清单登记规模与理由。
2. 用户确认后自行删除该目录；删除后由用户在清单追加一行（日期 + 范围）。
3. Agent 不得代为删除；不得用脚本批量匹配后删除（事故模式，见 `OUT_ARCHIVE_MANIFEST.md` 事故记录）。

## 6. 事故处理

若发生误删：① 立即停止作业；② 在清单"事故记录"写明时间、范围、被删对象类别、是否有证据受影响；
③ 评估可否重建；④ 复盘规则缺口并修订本文件。
